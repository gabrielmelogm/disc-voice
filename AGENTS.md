# Disc Voice
Esse projeto é um fork não oficial do discord, o objetivo é criar servidores, conversar com amigos e compartilhar a tela.

## Estrutura
apps - Aplicações desenvolvidas
  apps/api - Api do projeto
  apps/desktop - Aplicativo desktop do projeto

infra - Pasta que contém parte de infraestrutura do projeto
  infra/docker - Dockerfile, dockercompose, etc.
